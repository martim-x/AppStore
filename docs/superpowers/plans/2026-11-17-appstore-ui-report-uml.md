> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исправить подтверждённую прокрутку и обрезку текста в полях, снять и включить новые кадры пользовательских сценариев для гостя, пользователя и администратора, переписать пояснительную записку по существующим замечаниям и пересобрать DOCX/PDF.

WPF-сценарии запускать только на `appstore_test`, новые изображения проверять по содержимому и подставлять в руководство. **Tech Stack:** C# 12, .NET 8 WPF, xUnit, Entity Framework Core 8, PostgreSQL 16, draw.io, Python BstuReportBuilder v1.2.1, LibreOffice.

**Spec:** `docs/superpowers/specs/2026-11-16-appstore-ui-report-uml-design.md`

## Review Focus

- Поля профиля и формы добавления/редактирования должны показывать введённый текст целиком: переносить строки, расти по высоте и не иметь внутренней прокрутки.
- Длинные описания должны расширять TextBox от `MinHeight`; прокручивается внешняя форма, а не поле.
- `ProfilePopup` при ограничении по высоте рабочего стола должен прокручивать всё содержимое, включая выход; не обрезать нижнюю часть окна.
- `PART_ContentHost` передаёт настройки прокрутки из TextBox в обеих темах; PasswordBox-хост не центрируется вертикально.
- Скриншоты руководства должны соответствовать выбранной роли и реальному сценарию; кадры формы должны показывать корректный перенос текста без внутренних полос прокрутки.

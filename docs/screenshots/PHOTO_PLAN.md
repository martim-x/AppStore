# План изображений для пояснительной записки

Состояние на 17.11.2026. Для руководства отобраны реальные кадры приложения на тестовой базе `appstore_test`. Поля входа, регистрации, профиля и формы добавления пусты; личных данных в кадрах нет.

## Подходящие изображения для включения

- `manual/01_login.png`: русское окно входа с пустыми полями.
- `manual/02_catalog.png`: каталог пользователя в русской локализации.
- `manual/04_categories.png`: категории пользователя в виде плиточной сетки.
- `manual/09_admin_catalog.png`: каталог администратора с кнопкой «Добавить».
- `manual/10_add_form.png`: верхняя часть формы добавления с названиями, разработчиком и описаниями RU/EN.
- `manual/14_admin_add_form_bottom.png`: нижняя часть формы; поле категории и параметры приложения видны целиком. Снято пользователем 17.11.2026.
- `manual/05_app_card.png`: карточка приложения.
- `manual/08_profile.png`: чистый кадр панели профиля администратора в светлой теме; поля пустые, кнопка выхода видна. Файл заменён снимком пользователя 17.11.2026.
- `manual/07_installed.png`: список установленных приложений.
- `manual/06_rating.png`: состояние оценки в карточке.
- `manual/10_registration.png`: русская форма регистрации с пустыми полями.
- `manual/13_dark_app_card.png`: карточка приложения в тёмной теме. Это не кадр главного каталога.
- `17_registration.png`: пустая форма регистрации для описания начального состояния.
- `analogs/steam_store.png`, `analogs/app_store.png`: снимки магазинов-аналогов.
- `analogs/kupikod_store.png`: пользовательский снимок KupiKod от 15.11.2026.
- `UML/*.png`: схемы проекта, не снимки интерфейса.

- `placeholders/categories_not_captured.png`: заменена новым кадром `manual/04_categories.png`.

Файлы заглушек оставлены в каталоге, но в актуальной модели записки больше не используются.

## Кадры, исключённые из отчёта

- Поиск Figma: имеющийся `manual/03_search.png` показывает общий каталог, строка запроса не видна. Фигура не включена в текущую модель отчёта.
- Старые файлы `manual/09_admin_add.png` и `manual/14_admin_catalog.png` не используются; актуальны `manual/09_admin_catalog.png`, `manual/10_add_form.png` и `manual/14_admin_add_form_bottom.png`.
- `screenshots/08_dark_theme.png` показывает карточку вместе с открытым профилем. `manual/12_dark_catalog.png` показывает чистый каталог в тёмной теме без открытых фильтров и фрагментов рабочего стола.
- В `manual/02_catalog.png` для Adobe Photoshop показана цена `$43.99`, в `manual/09_admin_catalog.png` и `manual/12_dark_catalog.png` — `131 BYN`. Значения цен в тексте записки не сопоставляются.
